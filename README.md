## <a name="english-description">English Description</a>

A Java-based application designed for parsing boolean expressions and performing logical analysis. The tool automates the process of truth table generation and constructs perfect normal forms.

### Features
* **Expression Parsing:** Processes complex logical expressions with standard operators (AND, OR, NOT, Implication, Equivalence).
* **Truth Table Generation:** Automatically computes and displays full truth tables for any number of variables.
* **Normal Forms Generation:** Constructs Perfect Disjunctive Normal Form (SDNF) and Perfect Conjunctive Normal Form (SCNF).

### Tech Stack
* **Language:** Java (JDK 17+)
* **Concepts:** Abstract Syntax Trees (AST) / Stack-based parsing, Boolean Algebra.

## <a name="описание-на-русском">Описание на Русском</a>
Приложение на языке Java для парсинга логических выражений и проведения логического анализа. Инструмент автоматизирует процесс генерации таблиц истинности и построения совершенных нормальных форм.
### Функционал
* **Парсинг выражений:** Обработка сложных логических выражений со стандартными операторами (И, ИЛИ, НЕ, импликация, эквивалентность).
* **Генерация таблиц истинности:** Автоматический расчет и вывод полных таблиц истинности для любого количества переменных.
* **Построение нормальных форм:** Конструирование Совершенной дизъюнктивной нормальной формы (СДНФ) и Совершенной конъюнктивной нормальной формы (СКНФ).
### Стек технологий
* **Язык:** Java (JDK 17+)
* **Концепции:** Абстрактные синтаксические деревья (AST) / Парсинг на основе стека, булева алгебра.
