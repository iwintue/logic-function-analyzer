## <a name="english-description">English Description</a>

A Java-based application designed for parsing boolean expressions and performing logical analysis. The tool automates the process of truth table generation and constructs perfect normal forms.

### Features
* **Expression Parsing:** Processes complex logical expressions with standard operators (AND, OR, NOT, Implication, Equivalence).
* **Truth Table Generation:** Automatically computes and displays full truth tables for any number of variables.
* **Normal Forms Generation:** Constructs Perfect Disjunctive Normal Form (SDNF) and Perfect Conjunctive Normal Form (SCNF).

### Tech Stack
* **Language:** Java (JDK 17+)
* **Concepts:** Abstract Syntax Trees (AST) / Stack-based parsing, Boolean Algebra.
